# 家务奖惩记录本（jw）

一个给家里两个孩子记录家务奖励与行为惩罚的小工具：**每天记录奖罚，每周自动统计排名并结算金额，所有历史可查。**

打开网页就能用，不需要注册、不需要服务器、不需要安装任何东西。

- 在线使用：https://cxyo.github.io/jw/
- 项目地址：https://github.com/cxyo/jw

---

## 一、它能做什么

| 功能 | 说明 |
|---|---|
| 今日记录 | 选孩子 → 点奖惩项目 → 填实际金额和原因 → 保存，1 秒完成 |
| 两个小孩 | 默认「大宝 / 小宝」，姓名和头像都可以自己改 |
| 历史记录 | 按日期翻看任意一天，可按孩子筛选，自动汇总当天奖励、惩罚、净额 |
| 周报结算 | 按周一到周日统计：**本周排名**、每日收支柱状图、分类汇总、明细列表 |
| 金额结算 | 每周算出每个孩子应得的钱（奖励 − 惩罚），并标记该周是否已结算 |
| 数据备份 | 一键导出 JSON 文件，换电脑/换手机/换浏览器时导入即可恢复 |

## 二、奖惩规则来自哪里

项目内置的奖惩项目完整照搬自 `儿童家务与行为奖励惩罚表.docx`：

- **奖励 28 项**，分 4 大类
  - 🧹 家务劳动（10 项）：扫地拖地、洗碗擦桌、洗晾衣服、叠被铺床、洗袜洗鞋、倒垃圾拿快递、刷马桶、整理书桌、照顾弟妹、帮忙做饭…
  - 📖 学习与生活（9 项）：自主完成作业、自主阅读、复习预习、练字练球跳绳、单元考试 90 分以上、作息规律、不挑食、每天喝水、主动洗漱…
  - ✨ 品德与习惯（5 项）：不打架不吵架、不看电子屏幕、坐姿握笔标准、不哭不闹、礼貌待人
  - 🎁 特殊/出租项目（4 项）：连续一周全勤奖励、手机/电视/平板租借计时
- **惩罚 21 项**，分 5 大类
  - 😠 情绪与态度（5 项）：发脾气、顶嘴骂人、撒谎隐瞒、主动挑事、叫不理
  - 🍽️ 生活习惯（6 项）：挑食剩饭、不洗漱、乱扔东西、吃零食、厕所卫生、吃饭不上桌
  - 📚 学习与时间（3 项）：作业不认真、拖拉磨蹭、晚睡没时间观念
  - 📱 电子产品（3 项）：偷玩、超时、超半小时
  - 🛡️ 安全与财物（5 项）：打架、出门不带手表、乱花钱丢东西、破坏公物

每条项目都带有金额区间（如 1–2 元、-2 元、20 元/小时），记录时可在此区间内按实际表现填具体金额。部分项目（照顾弟妹、手机/电视/平板租借）是按小时计费。

## 三、怎么用

### 1. 直接在线用

打开 https://cxyo.github.io/jw/ 即可。建议在手机浏览器里「添加到主屏幕」，用起来跟 App 一样。

### 2. 本地用

双击 `index.html`，用 Chrome / Edge / Safari 打开就行，断网也能用。

### 3. 每天的操作流程

1. 顶部选中今天要记录的孩子
2. 切换「奖励 +」或「惩罚 -」
3. 点对应的项目卡片
4. 弹窗里填实际金额（默认填该项目的下限，可上下调整）和原因备注
5. 点「确认记录」

### 4. 每周日的结算流程

1. 切到「周报结算」标签
2. 看到两个孩子的**排名**（净收入高的排第一，带金牌）
3. 核对「每日收支」柱状图和「分类汇总」
4. 按排名卡片上的净额给孩子发钱
5. 点「标记本周已结算」，避免重复结算

## 四、数据存在哪？会不会丢？

数据保存在**你自己浏览器的 localStorage** 里，不会上传到任何服务器，也不经过 GitHub。

这意味着：

- ✅ 隐私安全，孩子的记录只有你自己看得到
- ⚠️ 数据跟着浏览器走：换浏览器、换设备、清理浏览器数据都会导致看不到旧记录
- ✅ 所以请定期点右上角「备份」导出 JSON 文件（建议每周结算后点一次）
- ✅ 换设备时用「恢复」导入这个 JSON 文件即可

> 注意：手机上添加到主屏幕后，和手机浏览器的数据是分开的两份，建议在其中一个端固定使用。

## 五、怎么改规则 / 改名字

**改孩子姓名和头像**：右上角「设置」→ 修改姓名、下拉选头像 → 保存。

**改奖惩项目或金额**：编辑 `index.html`（或 `家务奖惩记录本.html`），找到 `<script>` 里的这两个数组：

```js
const rewardItems = [
  { category: '🧹 家务劳动', name: '扫地 / 拖地', min: 1, max: 2, note: '视完成质量而定' },
  ...
];

const punishItems = [
  { category: '😠 情绪与态度', name: '发脾气 / 大喊大叫', min: 2, max: 2, note: '情绪失控' },
  ...
];
```

| 字段 | 含义 |
|---|---|
| `category` | 分类，相同 `category` 的项目会归到同一组 |
| `name` | 项目名称 |
| `min` / `max` | 金额区间；两者相等表示固定金额 |
| `perHour` | 设为 `true` 表示按小时计费（仅奖励项目需要） |
| `note` | 弹窗里显示的说明文字 |

加一个新项目就是往数组里加一行，保存文件刷新页面即可生效。已有的历史记录不受影响。

## 六、技术说明

- **纯前端单文件**：一个 `index.html`，HTML + CSS + 原生 JavaScript，零依赖、零构建
- **存储**：浏览器 `localStorage`（三个 key：记录、设置、已结算周）
- **部署**：GitHub Pages 静态托管
- **适配**：响应式布局，手机 / 平板 / 电脑都能用

### 本地开发

改完 `index.html` 直接刷新浏览器即可，没有编译步骤。

推送到 GitHub 后 Pages 会自动重新构建（通常 1 分钟内生效）：

```bash
git add -A
git commit -m "调整奖惩项目"
git push
```

## 七、常见问题

**Q：换了手机，记录不见了？**
A：数据在旧设备的浏览器里。请在旧设备上点「备份」导出 JSON，然后在新设备点「恢复」导入。

**Q：两个人的浏览器看到的数据不一样？**
A：这是正常的，数据不共享。如果希望两个家长共同记录，建议只在其中一台设备上记录。

**Q：能加第三个孩子吗？**
A：目前界面固定两个卡片。如果需要，可以改 `settings.children` 数组并调整对应的渲染逻辑。

**Q：金额能超过项目的区间上限吗？**
A：可以，输入框没做硬限制，按实际情况填就行（比如考试满分想多奖励）。

**Q：周是怎么划分的？**
A：按自然周，周一到周日。在「周报结算」里可以左右翻看历史各周。
